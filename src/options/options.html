Keyboard Shortcuts:

• Alt+[ / Alt+] (⌥[ / ⌥]) - Navigate backward/forward (customizable above)

• Alt+L (⌥L) - Show history popup

• Click extension icon - Show history popup


Note: Alt+L can also be customized at chrome://extensions/shortcuts

Alt+[ / Alt+] work on all web pages but are not shown in Chrome's shortcuts page due to API limitations.
