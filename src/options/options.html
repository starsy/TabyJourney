Keyboard Shortcuts

Set navigation and popup shortcuts in Chrome.

Find TabyJourney, then assign keys to “Navigate backward in tab history” and “Navigate forward in tab history”. Both start unassigned.

Use keys supported by Chrome, such as letters or arrows. Bracket keys [ ] are not supported.
